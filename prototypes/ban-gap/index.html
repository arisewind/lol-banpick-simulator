Ban 位间距方案对比

问题根因：ban-row-1 是 3 列、ban-row-2 是 2 列，grid 把行宽均分给列， 导致第二组格子更宽，槽居中后净距变成第一组的 2.5 倍（实测 33px vs 84px）。
四个方案共享同一套 BP 场景，只换 ban 行布局，点击打开对比。

方案 A · 固定槽宽 + 左对齐

最小改动：grid 里槽用 aspect-square + justify-self-center 改为左对齐，槽宽固定 64px 不随列数伸缩。两组槽间距物理完全相同。

ban-row-1 (3槽, gap 6px, 左对齐): [B1][B2][B3]________ 净距 6px 均匀 ban-row-2 (2槽, gap 6px, 左对齐): [B4][B5]____________ 净距 6px 同上 ✓

✓ 改动最小 · ✓ 间距完全一致 · ✓ 最接近 pickban.pro

✗ 第二组右侧留白较多

打开方案 A

方案 B · flex + 紧凑

ban 行从 grid 改成 flex，槽宽 56px、gap 4px，左对齐。两组物理距离完全相同，整体更省空间（留给 pick 更多宽度）。

ban-row-1 (flex, 56px, gap 4px): [B1][B2][B3]________ 紧凑左对齐 ban-row-2 (flex, 56px, gap 4px): [B4][B5]____________ 间距同上 ✓ 更省空间

✓ 最紧凑 · ✓ 间距完全一致 · ✓ 给 pick 更多空间

✗ ban 槽偏小(56px) · ✗ 第二组右侧留白

打开方案 B

方案 C · 两组两端对齐

两组都 flex + justify-between（两端对齐）。第一组 3 槽均匀分布在行宽两端及中间，第二组 2 槽分布在行宽两端。两组左右边缘严格对齐，形成整齐秩序感。

ban-row-1 (space-between, 3槽): [B1]________[B2]________[B3] ←两端对齐, 中间均匀分布→ ban-row-2 (space-between, 2槽): [B4]____________________[B5] ←两端对齐, 边缘与上组一致→

✓ 左右边缘严格对齐 · ✓ 秩序感强 · ✓ 两端对齐整齐

✗ 槽间距仍不一致(3槽密/2槽疏) · ✗ 中间留白大

打开方案 C

方案 D · 两组都居中（推荐）

两组都用 flex + justify-center，槽宽 64px、gap 6px。两组槽间距物理完全相同，且都居中显示，最对称美观。

ban-row-1 (flex + 居中, 64px): [B1][B2][B3] ←── 居中 ──→ ban-row-2 (flex + 居中, 64px): [B4][B5] ←── 居中 ──→ 间距完全相同(6px) ✓ 最对称

✓ 间距完全一致 · ✓ 两组都居中 · ✓ 最对称美观

✗ 第一组不再撑满(视觉变化最大)

打开方案 D
对比建议：A/B/C/D 四个原型的中间英雄池、pick 槽、配色完全相同，唯一差异是 ban 行布局。 建议四个标签页都打开，来回切换横向对比。选定后告诉我方案字母，我会把对应布局集成进 React 项目（TeamSection.tsx）。
